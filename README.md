# Lava Lamp (Android Live Wallpaper)

Энергоэффективные живые обои для Android с физической симуляцией настоящей лава-лампы, честным слиянием воска (**Metaball Coalescence**) и раскалённым внутренним свечением.

Рендеринг полностью перенесён на видеочип (**OpenGL ES 2.0 / GLSL** через нативный **C/JNI**-слой), что обеспечивает стабильные **120 FPS**, отсутствие нагрева процессора и минимальный расход аккумулятора даже на максимальном размере капель и кастомных фотообоях.

---

## Возможности

* **Аппаратное ускорение на GPU (OpenGL ES 2.0)**:
Вся пиксельная математика (скалярные поля плотности, расчёт 3D-нормалей, линзирование и освещение) выполняется параллельно видеочипом внутри быстрой памяти SRAM/GMEM без нагрузки на CPU.
* **Честное жидкое слияние (Metaballs)**:
Капли не являются спрайтами — они рассчитываются через непрерывное скалярное поле функции Wyvill ($C^2$-непрерывность). При сближении между ними плавно натягиваются жидкие перемычки без швов и стыков.
* **Оптика раскалённого воска (Incandescent & Bloom Glow)**:
Центр капли пылает ярким белым ядром от лампы накаливания снизу, переходя в плотный цвет воска с внешним неоновым ореолом рассеивания и зеркальными бликами.
* **Сила Архимеда и гироскоп**:
* Всплытие реагирует на реальный физический наклон устройства (`Sensor.TYPE_GRAVITY`).
* Зеркальная физика: при наклоне смартфона капли скользят в сторону наклона вдоль стенок колбы.


* **Двунаправленный поток (Dual-Mode Flow)**:
* **Снизу вверх ↑**: классическая лампа с донным резервуаром.
* **Сверху вниз ↓**: гравитационный водопад с автоматической инверсией геометрии капель и наклона гироскопа.


* **Раздельные обои для экрана блокировки и рабочего стола**:
* Независимая настройка фона для Lock Screen и Home Screen.
* Режимы: **Lava Aurora** (неоновые волны), **AMOLED Black** (абсолютно чёрный фон для максимальной экономии батареи) или **Своё фото из галереи** с аппаратным матовым преломлением (`GL_LINEAR`).


* **Гибкая настройка на лету**:
* Спектральная палитра любого цвета воска (**Hue 0°..360°**).
* Регулировка скорости всплытия (**0.5x .. 5.0x**).
* Регулировка максимального масштаба капель (**0.6x .. 2.0x**).
* Мгновенное применение настроек без перезапуска обоев.

## Установка

1. Перейдите во вкладку **Releases** репозитория (или скачайте APK-файл из корня).
2. Загрузите файл **`LavaLampHD.apk`** на смартфон.
3. Установите приложение (разрешите установку из неизвестных источников при необходимости).
4. Откройте приложение **«Aether Lava Lamp»** на рабочем столе для настройки цвета, скорости и фона, затем примените его как живые обои через системный диалог.

---

## Системные требования

* **Android**: 8.0 (API 26) или новее
* **Архитектура**: ARM64 (arm64-v8a)
* **Графика**: поддержка OpenGL ES 2.0+
